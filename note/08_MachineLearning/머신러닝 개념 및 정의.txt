머신러닝
정의
사무엘: 명시적으로 프로그램이 작성되지 않더라도 컴퓨터가 스스로 학습할수있는 능력을 제공
톰 미첼: 컴퓨터가 어떤 작업을 하는 데 있어서 경험으로부터 학습하여 성능에 대한 측정을 향상시키는 학문

ex: 바둑게임
T (Task, 작업): 머신러닝 시스템이 수행해야 하는 과제
바둑게임을 하는 일
P (Performance, 성능 측정): 모델의 실력을 평가하는 측정 기준
바둑게임에서 이길 확률 (승률)
E (Experience, 경험): 모델이 학습에 사용하는 데이터나 경험
수많은 바둑게임 판수 / 기보 데이터

머신러닝의 학습종류
지도학습 : 인풋 데이터에 대해서 올바른 정답(레이블)이 있는 데이터 집합이 주어지는 경우를 학습하는 것
	회귀 : 연속적인 값을 찾는 것/ feature을 이용해 예측 
		ex) 주가예측
	분류 : 미리 정의된 여러 class rable 중 하나를 예측
		이진분류: Y/N
		다중분류: 개,고양이 이미지 

ex) K-NN, 선형회귀, SVM, Decision Tree

비지도학습 : 인풋 데이터에 대해서 올바른 정답(레이블)이 없는 데이터 집합이 주어지는 경우를 학습하는 것
	군집 : 비슷한 것들끼리 하나의 cluster로 묶기
	ex) 구글뉴스에 적용되는 알고리즘
	시각화 : 숨겨진 구조와 패턴을 눈으로 직접 확인하는 작업
준지도학습 : 지도학습 + 비지도 학습
	ex) 페이스북 얼굴인식+태그기능

ex) K-Means, 계층군집화, 시각화, PCA


강화학습: 시행착오를 통해 최적의 행동 방식을 스스로 터득
	상태 인지: 에이전트가 현재 상태를 관찰 및 인지
	행동 결정: 현재 상태에서 보상을 가장 많이 받을 것 같은 행동을 선택
	환경 반응: 행동에 따른 상태 변화 및 보상 신호 부여
	최종 목표: 단기적인 보상뿐만 아니라, 시간이 흐르면서 받는 전체 보상의 		       	       합(누적 보상)을 극대화하는 최선의 정책을 도출

	ex) 	스키너의 쥐
		쥐 							에이전트 (Agent)
		상자 내부 환경					환경 (Environment)
		지레를 누르기 전/후 상황			상태 (State)
		지레를 누르는 행위				행동 (Action)
		먹이 (또는 전기 자극)				보상 (Reward) / 처벌 (Penalty)
		먹이를 먹기 위해 지레를 누르는 법칙	정책 (Policy)

머신러닝의 평가/목적
일반화 : 학습 데이터와 새로운 input 데이터가 들어와도 높은 성능을 유지하는 능력/목적

과대적합 : 학습 데이터 정확도 High + 새로운 데이터 정확도 Low
		원인 : 모델이 너무 복잡해서 학습 데이터의 지저분한 잡음(노이즈)이나 세세한 조건까지 달달 외워버림
		해결 방안 : 데이터 늘리기, 특성 줄이기, 조기 종료, 규제 적용
과소적합 : 학습 데이터 정확도 Low + 새로운 데이터 정확도 Low 
  		원인: 모델이 너무 단순하거나 공부량이 부족해서 데이터의 기본 패턴조차 파악하지 못함
		해결 방안 : 모델 복잡도 올리기, 공부량 늘리기, 특성 추가하기
