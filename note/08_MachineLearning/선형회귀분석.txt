머신러닝 학습 종류

1. 지도학습 (Supervised Learning)
   - 데이터와 레이블(정답)이 함께 제공되는 학습 방식
   - 회귀 (Regression): 연속적인 숫자 값을 예측 (예: 집값, 매출)
   - 분류 (Classification): 범주형 데이터 구분 (예: 스팸메일 여부)

2. 비지도학습 (Unsupervised Learning)
   - 레이블(정답)이 없는 데이터의 구조/패턴을 발견하는 학습 방식
   - 예: 군집화(Clustering), 차원축소(PCA)

3. 준지도학습 (Semi-supervised Learning)
   - 정답이 있는 일부 데이터와 정답이 없는 대량의 데이터를 함께 활용

4. 강화학습 (Reinforcement Learning)
   - 환경과의 상호작용을 통해 보상(Reward)을 최대화하는 행동 방침을 학습


선형회귀 분석 

1. 개념
   - 독립변수(x)와 종속변수(y) 간의 선형 관계를 모델링하여 연속적인 값을 예측
   - "평균으로의 회귀": 데이터의 오차를 관통하는 전체적인 평균 경향성(직선)을 찾는 기법

2. 가설 함수 (Hypothesis)
   - H(x) = Wx + b
   - W (Weight, 가중치): 직선의 기울기 (x가 y에 미치는 영향력)
   - b (Bias, 편향): y절편 (기본 바탕값)

3. 비용 함수 (Cost / Loss Function)
   - MSE (Mean Squared Error, 평균제곱오차)
   - Cost = (1/m) * Σ(H(x) - y)^2
   - 목적: 실제값(y)과 예측값(H(x))의 차이를 제곱하여 평균을 낸 후, 이 Cost 값을 최소화하는 W와 b를 산출

4. 최적화: 경사하강법 (Gradient Descent)
   - 비용함수를 최소화하기 위해 기울기(미분값)를 따라 W를 반복 업데이트하는 알고리즘
   - 공식: W := W - α * (∂Cost / ∂W)
     * α (Alpha): 학습률 (Learning Rate) - 이동할 보폭(Step Size)을 결정

5. 경사하강법의 주요 단점
   - 국소 최저점 (Local Minima): 전역 최저점이 아닌 도중의 작은 골짜기에 갇힐 위험
   - 안장점 (Saddle Point): 기울기가 0인 평평한 구간에서 학습이 정체
   - 계산 비용 (Batch GD): 매 업데이트마다 전체 데이터를 계산하므로 데이터가 크면 속도가 느림
   - 학습률 설정: α 값이 너무 크면 발산(Overshooting), 너무 작으면 학습 속도가 과도하게 느려짐
