다중 선형 회귀와 변수 선택법

1. 다중 선형 회귀 (Multiple Linear Regression)
- 정의: 여러 개의 독립변수(X1, X2, ..., Xp)를 사용해 하나의 종속변수(Y)를 예측하는 회귀 모델
- 수식: Y = β0 + β1*X1 + β2*X2 + ... + βp*Xp + ε
  * β0: 절편
  * β1~βp: 각 독립변수의 회귀계수 (영향력)
  * ε: 오차항

2. 전진선택법 (Forward Selection)
- 방식: 변수가 0개인 상태(절편만 존재)에서 출발하여, 종속변수를 가장 잘 설명하는 변수를 하나씩 추가
- 절차:
  1) 아무 변수도 없는 Null Model로 시작
  2) 모델에 없는 변수 중 P-value가 가장 낮거나 AIC/BIC 개선 효과가 큰 변수 탐색
  3) 해당 변수가 기준(유의수준 α = 0.05 등)을 만족하면 모델에 추가
  4) 더 이상 개선을 주는 변수가 없을 때까지 반복
- 장점: 계산량이 적고, 변수 개수가 데이터 수보다 많은 경우(p > n)에도 사용 가능
- 단점: 한 번 선택된 변수는 이후 단계에서 영향력이 낮아져도 제거되지 않음

3. 후진제거법 (Backward Elimination)
- 방식: 모든 독립변수를 포함한 상태에서 출발하여, 가장 유의하지 않은 변수를 하나씩 제거
- 절차:
  1) 모든 변수를 포함한 Full Model로 시작
  2) 모델 내 변수 중 P-value가 가장 높거나 가장 영향력이 적은 변수 탐색
  3) 해당 변수의 P-value가 임계값보다 크면 제거
  4) 남아있는 모든 변수가 유의성 기준을 만족할 때까지 반복
- 장점: 변수 간의 다중공선성 및 상호작용을 초기에 고려한 상태에서 제거 진행
- 단점: 변수 개수가 데이터 수보다 많은 경우(p > n) Full Model 추정이 불가능하여 사용 불가
