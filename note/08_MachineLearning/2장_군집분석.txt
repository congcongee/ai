군집분석 

1. 군집분석 개요
- 클러스터(Cluster): 특성이 유사한 데이터들의 그룹
- 클러스터링(Clustering): 유사한 데이터를 그룹으로 나누는 비지도학습
- 주요 유형: K-Means, Hierarchical, DBSCAN

2. K-Means 클러스터링
- 중심점(Centroid)을 기준으로 데이터를 K개 군집으로 분류
- 군집 내 데이터와 중심점 사이의 거리 제곱합을 최소화하도록 반복

from sklearn.cluster import KMeans
KMeans(n_clusters=k, init='k-means++', max_iter=300, n_init='auto')

- k-means++: 초기 중심점을 효과적으로 선택하는 방법
- fit(X): 학습 / predict(X): 군집 예측
- labels_: 군집 번호 / cluster_centers_: 중심점 좌표

3. Hierarchical 클러스터링
- 데이터 간 거리를 기준으로 가까운 군집을 단계적으로 병합
- 덴드로그램으로 계층 구조 확인

from scipy.cluster.hierarchy import linkage, dendrogram, fcluster

- linkage(data, method='complete'): 계층적 군집 생성
- dendrogram(model): 계층 구조 시각화
- fcluster(model, t, criterion='distance'): 거리 기준 군집 분류
- criterion='maxclust': 군집 개수 기준 분류

4. DBSCAN 클러스터링
- 데이터 밀도를 기준으로 군집 형성
- 군집 개수 지정 불필요, 이상치는 -1로 표시

from sklearn.cluster import DBSCAN
DBSCAN(eps=0.3, min_samples=10)

- eps: 주변 탐색 반경
- min_samples: 핵심 데이터 판단에 필요한 최소 샘플 수(자기 자신 포함)
- fit(X): 학습 / labels_: 군집 결과

5. 군집모형 평가

[정답이 있는 경우: 외부 평가]
- adjusted_rand_score: 실제 군집과 예측 군집의 일치 정도
- mutual_info_score / normalized_mutual_info_score: 군집 간 정보 공유 정도
- homogeneity_score: 한 군집에 같은 정답 클래스가 모인 정도
- completeness_score: 같은 정답 클래스가 한 군집에 모인 정도
- v_measure_score: 균일성과 완전성의 조화평균

[정답이 없는 경우: 내부 평가]
- silhouette_score(X, labels): 군집 내 응집도와 군집 간 분리도 평가
- 값 범위: -1 ~ 1, 일반적으로 1에 가까울수록 좋음
- 군집 품질 평가 및 적절한 군집 개수 탐색에 활용
