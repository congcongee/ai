모듈 : 함수, 변수, 클래스 등을 담고 있는 파이썬 코드 파일(*.py)

모듈/패키지이나 모듈안의 함수를 가져오는 방법
1. import A                 - A모듈을 가져옴    
2. import A as B            - A모듈을 B이름으로 가져옴
3. from A import B          - A모듈안의 B함수(클래스|변수)를 가져옴
4. from A import B as C     - A모듈안의 B함수를 C이름으로 가져옴
5. from A import B          - A패키지안의 B모듈을 가져옴
6. from A.B import C        - A패키지안의 B모듈안의 C함수 가져옴
7. from A import B as C     - A패키지안의 B모듈을 C이름으로 가져옴
8. from A.B import C as D   - A패키지안의 B모듈안의 C를 D이름으로 가져옴

패키지 설치 및 삭제
아나콘다 프롬프트에서
- 패키지 설치 : pip install 패키지명[==버전] / conda install 패키지명[==버전] / uv pip install 패키지명[==버전]
- 패키지 확인 : pip show 패키지명           / conda list 패키지명
- 패키지 삭제 : pip uninstall 패키지명      / conda remove 패키지명
