1. 글자 관련 태그
<h1> ~ <h6> : 제목 태그. 숫자가 작을수록 중요도와 기본 글자 크기가 큼. 자동 개행
<p> : 단락(Paragraph) 태그. 문단을 만들며 기본 여백이 생김
<i> : 이탤릭체(기울임)
<b> : 글자를 굵게 표시
<strong> : 의미적으로 중요한 내용을 강조. 기본적으로 굵게 표시
<sup> : 윗첨자
<sub> : 아랫첨자
<ins> : 삽입된 내용을 의미. 기본적으로 밑줄 표시
<del> : 삭제된 내용을 의미. 기본적으로 취소선 표시
<span> : 인라인 영역을 구분하는 태그. CSS 적용 등에 사용
<a> : 링크 태그. href 속성으로 이동할 주소 지정


페이지 내 이동
<a href="#id명">이동하기</a>

<h2 id="id명">이동할 위치</h2>


2. 목록 태그

[순서가 없는 목록]
<ul>
    <li>사과</li>
    <li>바나나</li>
    <li>포도</li>
</ul>

<ul> : 순서가 없는 목록 (Unordered List)
<li> : 목록의 각 항목 (List Item)

type 속성
- disc : 기본 점
- circle : 빈 원
- square : 사각형

[순서가 있는 목록]
<ol>
    <li>첫 번째</li>
    <li>두 번째</li>
    <li>세 번째</li>
</ol>

<ol> : 순서가 있는 목록 (Ordered List)
<li> : 목록의 각 항목

type 속성
- 1 : 숫자
- a : 소문자
- A : 대문자
- i : 로마 숫자 소문자
- I : 로마 숫자 대문자

3. 표(Table) 태그

[기본 구조]
<table>
    <caption>학생 정보</caption>
    <tr>
        <th>이름</th>
        <th>나이</th>
    </tr>
    <tr>
        <td>홍길동</td>
        <td>20</td>
    </tr>
</table>

<table> : 표 전체를 감싸는 태그
<caption> : 표의 제목
<tr> : 표의 행 (Table Row)
<th> : 제목 셀 (Table Header). 기본적으로 굵게, 가운데 정렬
<td> : 일반 셀 (Table Data)


[셀 병합]
<td colspan="2">가로 2칸 병합</td>
colspan="N" : 가로 방향으로 N개의 열(칸) 병합

<td rowspan="2">세로 2칸 병합</td>
rowspan="N" : 세로 방향으로 N개의 행(줄) 병합


4. 이미지 태그
<img src="image.jpg" alt="이미지 설명">

<img> : 이미지를 출력하는 태그. 닫는 태그가 없는 단독 태그
src : 이미지 경로. 상대경로 또는 웹 URL
alt : 이미지가 표시되지 않을 때의 대체 텍스트. 웹 접근성에도 중요
width : 이미지 너비
height : 이미지 높이

ex) <img src="cat.jpg" alt="고양이 사진" width="300" height="200">


5. 가로 구분선
<hr> : 주제나 내용을 구분하는 가로선
- 닫는 태그가 없는 단독 태그


6. 오디오 태그
[기본 구조]
<audio controls>
    <source src="music.mp3">
</audio>

<audio> : 오디오 재생 태그
controls : 재생, 일시정지, 볼륨 등의 조작 UI 표시
preload : 오디오 파일의 사전 로드 설정
preload="auto" : 페이지 로드 시 오디오를 미리 로드
loop : 오디오 반복 재생
<source> : 오디오 파일의 경로 및 형식 지정

ex) <audio controls loop>
   	<source src="music.mp3">
     </audio>

7. 핵심 태그 한눈에 보기
제목       : <h1> ~ <h6>
단락       : <p>
글자 강조   : <b>, <strong>, <i>
첨자       : <sup>, <sub>
밑줄/취소선 : <ins>, <del>
영역 구분   : <span>
링크       : <a>
순서 없는 목록 : <ul>, <li>
순서 있는 목록 : <ol>, <li>
표         : <table>, <tr>, <th>, <td>
이미지     : <img>
구분선     : <hr>
오디오     : <audio>, <source>


<기본적으로 기억할 구조>
제목      → h1 ~ h6
문단      → p
링크      → a
목록      → ul / ol + li
표        → table + tr + th / td
이미지    → img
오디오    → audio + source
영역 구분 → span
