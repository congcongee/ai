[ CSS 기본 ]

선택자 {

속성: 값;

}

color : 글자 색
background-color : 배경 색
font-size : 글자 크기
font-weight : 글자 굵기
text-align : 가로 정렬
line-height : 줄 높이 / 줄 간격
width / height : 너비 / 높이
border : 테두리
margin : 바깥 여백
padding : 안쪽 여백
opacity : 투명도
display : 요소의 표시 방식

[ 선택자 ]
: 전체 선택자
태그 : 태그 선택자
#id : ID 선택자
.class : 클래스 선택자

[ 가상 클래스 ]
:first-child : 첫 번째 자식
:last-child : 마지막 자식
:nth-child(n) : n번째 자식
:nth-child(2n) : 짝수 번째
:nth-child(2n+1) : 홀수 번째
:hover : 마우스를 올렸을 때
:focus : 포커스 되었을 때

[ 자식 선택자 / 후손 선택자 ]
div p : div 안의 모든 p
- 후손 선택자
div > p : div 바로 아래의 p
- 자식 선택자

[ 형제 선택자 ]
h3 + div : h3 바로 다음 형제 1개
h3 ~ div : h3 뒤의 형제 전체

[ Box Model ]
요소의 크기와 여백을 구성하는 기본 구조
content : 실제 내용
padding : 내용과 테두리 사이의 안쪽 여백
border : 테두리
margin : 테두리 바깥쪽 여백
margin: 0 auto;
- 좌우 여백을 자동으로 설정하여 가운데 배치
box-sizing: border-box;
- border와 padding을 width / height에 포함

[ display ]
display: block;
- 한 줄을 차지하는 블록 형태
display: inline;
- 필요한 만큼만 공간을 차지하는 인라인 형태
display: inline-block;
- inline처럼 배치하면서 width / height 지정 가능
display: none;
- 화면에서 사라지고 공간도 없어짐
visibility: hidden;
- 화면에서 사라지지만 공간은 유지
opacity: 0;
- 완전히 투명하게 표시

[ float ]
float: left;
- 요소를 왼쪽으로 띄워 가로 배치
clear: both;
- float 해제
overflow: hidden;
- 부모 요소가 float 자식 요소의 영역을 인식하도록 정리할 때 사용

[ 목록 메뉴 ]
ul li { float: left; }
- 목록을 가로로 배치
list-style: none;
- 목록 앞의 기호 제거
li a { display: block; }
- 링크 영역을 블록 형태로 변경

[ 텍스트 정렬 ]
text-align: center;
- 가로 가운데 정렬
text-align: justify;
- 양쪽 정렬
line-height: 300px;
- height와 같은 값으로 설정하면 한 줄의 글자를 세로 가운데 배치할 때 사용

[ 폰트 ]
font-family : 글꼴 지정
font-size : 글자 크기
font-weight : 글자 굵기
font-style : 글자 스타일
text-decoration : 글자 장식
font-style: italic;
- 기울임꼴
text-decoration: underline;
- 밑줄
@font-face
- 로컬에 있는 폰트를 웹폰트처럼 사용
@import
- 외부 CSS / 웹폰트 불러오기

[ 배경 ]
background-color : 배경 색
background-image : 배경 이미지
background : 배경 관련 속성을 한 번에 지정
background: url(...) center no-repeat;
- 배경 이미지 지정 + 가운데 배치 + 반복 없음
background-size
- 배경 이미지 크기 조절

[ 테두리 ]
border: 1px solid black;
- 두께 1px / 실선 / 검정색
border-radius
- 모서리를 둥글게 설정
border-radius: 50%;
- 정사각형 요소를 원형에 가깝게 만들 때 사용

[ 위치 지정 ]
position: static;
- 기본 위치 방식
position: relative;
- 현재 위치를 기준으로 이동
- 자식의 absolute 위치 기준으로 사용하기도 함
position: absolute;
- 기준이 되는 위치를 기준으로 절대 위치 지정
position: fixed;
- 화면을 기준으로 고정
top / right / bottom / left
- 위치 조정

[ z-index ]
z-index : 요소가 겹칠 때 앞뒤 순서 지정
z-index 값이 클수록 위에 표시

[ 투명도 ]
opacity: 0;
- 완전 투명
opacity: 1;
- 완전 불투명
opacity: 0.5;
- 반투명

[ 크기 단위 ]
px : 픽셀 단위
% : 부모 요소를 기준으로 한 비율
em : 현재 요소의 글자 크기를 기준으로 한 상대 단위
pt : 포인트 단위

[ 가운데 정렬 ]
가로 가운데 정렬
margin: 0 auto;
text-align: center;
세로 가운데 정렬
한 줄인 경우 height와 line-height를 같게 설정

[ 기타 ]
border-collapse: collapse;
- 테이블의 겹치는 테두리를 하나로 합침
text-decoration: none;
- 링크의 밑줄 제거
box-sizing: border-box;
- padding과 border를 요소의 width / height 안에 포함
display: block;
- inline 요소 등을 block 형태로 변경
