HTML & CSS 선택자 핵심 정리

[ CSS 기본 ]
선택자 { 속성: 값; }

- color : 글자 색
- background-color : 배경 색
- font-size : 글자 크기
- font-weight : 글자 굵기
- text-align : 정렬
- border : 테두리
- margin : 바깥 여백
- padding : 안쪽 여백
- width / height : 크기

[ 기본 선택자 ]
- * : 전체 선택자
- 태그 : 태그 선택자
- #id : ID 선택자
- .class : 클래스 선택자

[ 선택자 조합 ]
- div p : div 안의 모든 p → 후손 선택자
- div > p : div 바로 아래 p → 자식 선택자
- h3 + div : h3 바로 다음 형제 1개
- h3 ~ div : h3 뒤의 형제 전체

[ 속성 선택자 ]
- [속성] : 해당 속성이 있는 요소
- [속성="값"] : 속성값이 같은 요소
- [속성^="값"] : 특정 값으로 시작
- [속성$="값"] : 특정 값으로 끝남

예)
- input[type="password"]
- input[type^="te"]
- input[name$="me"]

[ 가상 클래스 ]
- :hover : 마우스를 올렸을 때
- :focus : 포커스 되었을 때
- :enabled : 활성화된 요소
- :disabled : 비활성화된 요소
- :read-only : 읽기 전용 요소
- :first-child : 첫 번째 자식
- :last-child : 마지막 자식
- :nth-child(2n) : 짝수 번째
- :nth-child(2n+1) : 홀수 번째

[ Box Model ]
- margin : 바깥 여백
- padding : 안쪽 여백
- margin: 0 auto;
  - 좌우 여백을 자동으로 설정하여 가운데 배치

[ float ]
- float: left;
  - 요소를 가로로 배치
- clear: both;
  - float 해제
- overflow: hidden;
  - 부모 영역 정리

[ 목록 메뉴 ]
- float: left;
  - 메뉴 가로 배치
- list-style: none;
  - 목록 기호 제거

[ 기타 ]
- border-collapse: collapse;
  - 테이블 테두리 합치기
- text-decoration: none;
  - 링크 밑줄 제거
- tr:hover
  - 마우스를 올렸을 때 테이블 행 스타일 변경
