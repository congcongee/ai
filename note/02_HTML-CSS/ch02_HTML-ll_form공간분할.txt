HTML Form 및 레이아웃 정리

1. Form 태그
<form> : 사용자 입력을 받아 전송하는 영역
action : 데이터를 전송할 주소
method : 데이터 전송 방식
- get : URL에 입력값 표시
- post : URL에 입력값 표시하지 않음

[input 주요 type]
text : 한 줄 문자 입력
password : 비밀번호 입력
tel : 전화번호 입력
number : 숫자 입력
email : 이메일 입력
file : 파일 선택
date : 날짜 선택
radio : 여러 항목 중 하나 선택
checkbox : 여러 항목 선택
hidden : 화면에 보이지 않고 값 전송
button : 일반 버튼
submit : 폼 전송
reset : 입력 내용 초기화

[input 주요 속성]
name : 입력값의 이름
value : 입력값
size : 입력창 크기
min / max : 최솟값 / 최댓값
checked : 기본 선택
placeholder : 입력 안내 문구
autocomplete="off" : 자동완성 끄기

2. 기타 입력 태그
<select> : 목록 선택
<option> : 목록 항목
<select multiple> : 여러 항목 선택
size : 목록에 표시할 항목 수
<textarea> : 여러 줄 입력
cols : textarea 가로 크기
rows : textarea 세로 크기
<label> : 입력 요소의 설명
for : label과 input의 id 연결

3. 입력 유효성 검사
required : 필수 입력
minlength : 최소 글자 수
maxlength : 최대 글자 수
pattern : 입력 형식 검사
title : 입력 형식이 맞지 않을 때 안내 문구
autofocus : 페이지 실행 시 입력창에 자동으로 커서 위치

4. JavaScript 유효성 검사
<form onsubmit="return chk()">
onsubmit : 폼 전송 시 함수 실행
return false : 전송 취소
return true : 전송

[주요 사용법]
frm.입력요소.value : 입력값 가져오기
trim() : 앞뒤 공백 제거
length : 문자열 길이
focus() : 입력창에 커서 위치
alert() : 경고창 표시

5. 게시판 Form
제목 : <input type="text">
작성자 : <input type="text">
본문 : <textarea>
첨부파일 : <input type="file">
글쓰기 : <input type="submit">
초기화 : <input type="reset">

[필수 입력]
required : 필수 입력
minlength : 최소 글자 수

6. 블록형 / 인라인형 태그

[블록형 태그]
- 한 줄 전체를 차지
- 다음 요소가 다음 줄에 배치
- <div>, <p>, <ul>, <li>

[인라인형 태그]
- 필요한 공간만 차지
- 같은 줄에 이어서 배치
- <span>

7. 공간 분할 태그
<div>
- 웹페이지의 영역을 나누는 태그
- id를 사용하여 영역 구분
ex)
<div id="header">헤더</div>
<div id="nav">메뉴</div>
<div id="content">본문</div>
<div id="footer">하단</div>

8. 시맨틱 태그
<header> : 헤더 영역
<nav> : 네비게이션 영역
<section> : 콘텐츠 영역
<footer> : 하단 영역

[<div>와 시맨틱 태그]
<div> : 의미 없이 영역을 구분
<header>, <nav>, <section>, <footer> : 영역의 의미를 나타냄
